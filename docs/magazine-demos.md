# Magazine demonstration articles

```
npx vite-node --config vitest.config.ts scripts/seed-magazine-demos.ts
```

The script skips any title that already has a live guide, so it's safe to run again. Nothing is published: review each one in the Magazine editor, resolve its flags, and publish.

## Flags to resolve before publishing

Blocks flagged **verify** hold publishing until a reviewer confirms them:

- **Expert guidance, "If someone is hurt":** the partner incident route to name (the Incident Submission Form or a phone number), and the timeframe partners must meet.
- **Brokered onboarding, "The people you’ll work with":** what Compliance audits for brokered partners, and how often.
- **Brokered onboarding, "Your first 90 days":** whether the P1 30/60/90-day plan applies to brokered partners, and what each milestone is.

Blocks flagged **illustrative** are made-up examples or linking copy, marked for reviewers:

- the invoice example's names and $65 rate;
- the three perspectives;
- the suggested wording;
- the briefing list;
- the partner guidance in each journey phase;
- a placeholder link from the onboarding course to the invoices guide.

## The Hub diagram block

New for these articles: **Add block → Explore → Hub diagram** (`hubvisual`). It shows one of the Hub's own diagrams inside an article:

- the client journey map (its feeling curve and road), or
- a partner model's who-does-what onboarding diagram (P1, brokered or coordinator managed).

It's drawn from the same content as the diagram's own page, so an article never shows an out-of-date copy. It has a caption and a link to the full page. Nothing to complete; no sign-off.
